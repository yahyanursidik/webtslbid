# 26 — Definition of Done

A page is done only if:

## Product
- purpose clear,
- next action clear,
- content approved.

## Design
- follows design system,
- no banned motifs,
- mobile and desktop reviewed.

## Development
- build passes,
- no console errors,
- component naming clean,
- no unnecessary JS.

## Content
- facts verified,
- religious references reviewed,
- no placeholders.

## SEO
- metadata complete,
- canonical correct,
- indexability intentional.

## Accessibility
- keyboard usable,
- headings correct,
- contrast acceptable.

## Performance
- optimized images,
- acceptable Lighthouse/Core Web Vitals.
