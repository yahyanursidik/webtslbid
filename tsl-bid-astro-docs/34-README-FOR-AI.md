# README for AI Coding Assistant

Sebelum coding:
1. baca `00-MASTER-INSTRUCTION.md`,
2. baca file yang relevan dengan tahap kerja,
3. jangan invent data,
4. jangan ubah scope tanpa alasan,
5. jangan upgrade dependency secara diam-diam,
6. jangan membuat imagery palsu.

- jelaskan hasil,
- list file berubah,
- jalankan build/check,
- beri tahu error,
- berhenti pada batas tahap.

Prioritas:
Correctness > clarity > accessibility > performance > visual novelty.
