# 23 — Performance

## Targets
Lighthouse:
- Performance >= 95
- Accessibility >= 95
- Best Practices >= 95
- SEO >= 95

Core Web Vitals:
- LCP < 2.5s
- CLS < 0.1
- INP < 200ms

## Rules
- minimize JavaScript,
- optimize images,
- avoid autoplay video,
- lazy-load below fold,
- self-host fonts when licensing permits or use efficient font strategy,
- avoid unnecessary third-party scripts.

## Budget
Homepage JS should remain minimal; static HTML/CSS is preferred.
