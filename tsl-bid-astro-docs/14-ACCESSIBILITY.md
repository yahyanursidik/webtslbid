# 14 — Accessibility

Target minimum WCAG 2.2 AA.

## Checklist
- semantic HTML,
- correct headings,
- skip-to-content,
- keyboard navigation,
- visible focus,
- accessible mobile menu,
- labels on forms,
- alt text,
- no information conveyed by color only,
- reduced motion,
- proper link text,
- contrast AA.

## Images
Decorative images:
- empty alt

Meaningful documentation:
- descriptive alt

## Arabic
Gunakan proper language attributes bila relevan:
```html
<span lang="ar" dir="rtl">...</span>
```
