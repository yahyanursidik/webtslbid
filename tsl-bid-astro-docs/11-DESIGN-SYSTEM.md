# 11 — Design System

```css

--color-primary-soft: #E3ECE6;
```

Final color may change after visual exploration.

## Typography
Sans:
- Plus Jakarta Sans / Inter / Geist

Optional editorial serif:
- Source Serif 4 / Newsreader

## Radius
Gunakan moderat.
Tidak semua card membutuhkan rounded corners.

## Shadow
Minimal.
Gunakan border/divider lebih dahulu.

## Spacing
Gunakan consistent spacing scale.

## Max Width
- layout: 1200–1280px
- reading: 680–760px

## Buttons
Primary:
- solid primary

Secondary:
- text/border

Jangan gunakan pill button berlebihan.
