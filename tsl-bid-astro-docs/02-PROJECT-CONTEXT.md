# 02 — Project Context

## Organisasi
Tarbiyah Sunnah Learning merupakan bagian dari ekosistem pendidikan/dakwah Yayasan Tarbiyah Sunnah.

## Program Utama Website
Belajar Islam Dasar (BID).

## Konteks Redesign
Website baru harus meningkatkan:
- clarity,
- trust,
- navigation,
- SEO,
- performance,
- conversion,
- maintainability.

## Karakter Brand
- ilmiah tetapi tidak kaku,
- Islami tanpa ornamen klise,
- tenang,
- bersih,
- kredibel,
- ramah bagi masyarakat umum,
- tidak hiperbolik.

## Prinsip Narasi
Jangan menggunakan:
- “program terbaik”
- “pasti berubah”
- “paling lengkap”
- klaim berlebihan lain yang tidak dapat dibuktikan.

Gunakan:
- penjelasan konkret,
- struktur,
- manfaat,
- mekanisme,
- hasil belajar yang realistis.

## Catatan Migrasi
Konten lama harus diaudit sebelum dimigrasikan.
Periksa:
- judul,
- deskripsi mata pelajaran,
- data pengajar,
- jadwal,
- biaya,
- FAQ,
- link pendaftaran,
- teks Arab,
- kutipan,
- typo,
- duplikasi,
- konten yang sudah tidak berlaku.
