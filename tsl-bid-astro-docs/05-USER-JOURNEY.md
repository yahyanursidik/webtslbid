# 05 — User Journey

## Main Conversion Journey
```text
Need
↓
Understand BID
↓
Understand structure
↓
See curriculum
↓
Know teachers
↓
Understand learning system
↓
Trust
↓
Register
↓
Enter learning portal
```

## UX Requirements
- CTA “Daftar BID” harus terlihat jelas di header dan section akhir.
- Setiap page akademik harus memiliki CTA lanjutan.
- Jangan membuat user dead-end.
- Breadcrumb untuk halaman dalam.
- Mobile CTA tidak boleh menutupi konten.
- FAQ harus menjawab keraguan sebelum registrasi.

## Micro-conversions
Track:
- click curriculum
- click teacher
- click registration
- click login
- click FAQ
- click WhatsApp/help
