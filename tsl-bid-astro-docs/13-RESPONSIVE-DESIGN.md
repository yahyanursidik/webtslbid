# 13 — Responsive Design

## Mobile First
Test minimum:
- 360px
- 375px
- 390px
- 412px
- 430px
- tablet
- 1280px+
- 1440px+

## Rules
- no horizontal scroll,
- tap target >= 44px,
- body text nyaman dibaca,
- CTA tidak terlalu rapat,
- navbar accessible,
- card tidak dipaksa grid bila konten lebih baik stack.

## Hero
Mobile:
- heading readable,
- CTA stack bila perlu,
- tidak ada hero visual yang mengambil >60% layar.

## Tables
Hindari tabel untuk data yang lebih baik disusun sebagai list pada mobile.
